# PHARM MASTER

Nursing pharmacology study app (single-file HTML) for HESI PN Exit prep.

- `pharm-master.html` — the built app; open it in a browser.
- `src/` — source files. Run `python3 build.py` to rebuild the HTML from `src/`.
- `test*.py`, `tests/`, `check.js`, `audit/` — automated tests (Playwright / Node).
- `backups/` — earlier versions of the app.

For education only — not for real-time medication administration decisions.
